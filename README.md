# 🎡 گردون — Gardoon

> **چرخه رو تو بگردون**

اپلیکیشن اندروید مدیریت حرفه‌ای بازی **مافیا** برای گرداننده (خداوند) — کاملاً فارسی و کاملاً آفلاین.

---

## 🎯 گردون چیست؟

گردون ابزار گرداننده بازی مافیا است. به‌جای کارت‌های کاغذی، تایمر گوشی و یادداشت‌های پراکنده، گرداننده همه‌چیز را در یک اپ دارد:

- **🃏 میزگرد** — اجرای کامل بازی: توزیع نقش، مدیریت شب و روز، تایمر، رأی‌گیری، اعلام نتایج
- **🛠 سناریوساز** — بیلدر گرافیکی که کاربر با آن می‌تواند **تمام قوانین** سناریو را تغییر دهد و سناریوی خودش را بسازد
- **🎲 نقش‌کشه** — توزیع هوشمند و تصادفی نقش‌ها بین بازیکنان
- **📦 فرمت `.grdn`** — هر سناریو یک فایل اختصاصی است که می‌توان ذخیره، اشتراک‌گذاری و بین گروه‌ها جابه‌جا کرد

---

## 🏛 فلسفه محصول

در ایران هر گروه مافیاباز **قوانین خودش** را دارد و همیشه سر جزئیات بحث است. گردون به‌جای تحمیل قوانین، **قانون‌سازی را به کاربر می‌سپارد** — با سناریوساز گرافیکی ۴ سطحی که از تنظیمات ساده تا طراحی بلوکی توانایی‌ها و شرط‌برد بصری پیش می‌رود.

## ✨ ویژگی‌های کلیدی

| ویژگی | توضیح |
|--------|--------|
| 🔌 کاملاً آفلاین | بدون نیاز به اینترنت — همه‌چیز روی گوشی |
| 🇮🇷 کاملاً فارسی | رابط کاربری و همه سناریوهای پیش‌فرض |
| 🎨 سناریوساز گرافیکی | ۴ سطح عمق: فرم‌ها ← بلوک‌های توانایی ← شرط‌برد بصری ← رویدادهای تصادفی |
| 📦 فرمت باز `.grdn` | سناریو = فایل قابل اشتراک (کانتینر ZIP + JSON) |
| 🍮 افکت گویی | رابط کاربری مایع و ارگانیک به سبک Liquid Gooey |
| 🌗 دو تم | تاریک و روشن — انتخاب با کاربر |

## 🛠 خلاصه فنی

- **فریم‌ورک:** Flutter (فقط اندروید)
- **حداقل اندروید:** Android 7 (API 24)
- **زبان رابط:** فقط فارسی
- **State Management:** Riverpod
- **دیتابیس:** فایل‌محور + shared_preferences (جزئیات در architecture.md)
- **اشتراک‌گذاری سناریو:** فایل `.grdn` + QR Code
